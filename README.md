# Halo

The iPad next to your Mac, as a calm, always-on companion surface. See [`docs/PRD.md`](docs/PRD.md).

```sh
brew install xcodegen
xcodegen generate
open Halo.xcodeproj
```

- `Apps/HaloPad` — iPad app
- `Apps/HaloMac` — Mac menu bar helper
- `Packages/HaloKit` — shared code (`HaloCore`, `HaloProtocol`)

Contributor and agent guidance lives in [`AGENTS.md`](AGENTS.md).
