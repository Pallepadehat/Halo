# Security and privacy

Halo lets an iPad move your Mac's pointer, answer your coding agents' permission prompts and run your Shortcuts, so its security promises matter:

- Only an iPad you've paired, by confirming the same code on both screens, can connect. Everything after that is encrypted.
- Nothing leaves your local network. There's no account, no server, no analytics.
- If the Mac helper isn't running, agents behave exactly as if Halo weren't installed.

If you find a way around any of that (an unpaired device connecting, traffic readable on the network, a way to approve an agent's request or move the pointer without the paired iPad, anything leaving the local network), please **don't open a public issue**. Report it privately through [GitHub's security advisories](https://github.com/Pallepadehat/Halo/security/advisories/new). You'll get a reply within a week.
